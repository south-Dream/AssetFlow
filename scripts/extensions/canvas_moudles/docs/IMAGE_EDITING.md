# 图片工具与 Inspector 布局

左侧工具栏只放图片内容操作：裁剪、调整尺寸、画布补边、旋转翻转、透明裁剪、移除背景。格式转换和重命名不再作为编辑工具，也不出现在“编辑 → 工具”列表。

文件 → 保存（Ctrl+S）把当前画布的操作结果更新到关联的内部资产；导入源文件和内部不可变底图不受影响，操作链保留以便继续编辑。有效的当前草稿一并提交。文件 → 导出打开文件/文件夹勾选面板，输出 ZIP 或新目录；存在未保存修改时先确认保存。默认按资产保存的格式和名称导出；图片输出设置可选择 PNG / JPEG / WebP、质量、JPEG 背景以及命名模板。仅重命名保持原字节，转换和命名只作用于导出包，不修改已保存资产与操作链。不再提供独立的单图输出窗口或面板配置入口。

Inspector 使用统一的上下分区：上方为框架输入源、预览目标等固定属性，下方为当前选中工具参数。两区各自滚动，中间分隔条可拖动，也可用方向键调整。没有操作记录或历史步骤列表。

图片操作使用独立草稿，参数和“应用 / 取消”在 Inspector 下方。画布只承担预览、选区和拖动交互，不再放尺寸输入、缩放参数、预设或应用按钮。调整尺寸的宽高、比例锁、百分比快捷入口放在 Inspector；交互编辑统一为精确宽高模式，使手柄预览与提交结果一致。裁剪越界、无效尺寸及超限参数不能应用。

裁剪输入预览的加载依赖前置步骤的内容，而非每次渲染新建的数组引用，防止反复载入、重置参数和闪烁。调节草稿参数不重新加载原输入图。工具提示使用宿主独立浮层显示 name + desc，不再仅依赖浏览器原生 title。
