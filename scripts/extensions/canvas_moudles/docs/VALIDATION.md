# 实施与验证记录

日期：2026-10-27。

## Inspector 配置与 Drawer 扩展

新增 inspector.canvas 常驻字段、inspector.operations 按工具 ID 注入，统一字段 order、标准 input/slider/button 和 namespaced renderer。上方属性独立于操作选择，按实例保存并写入面板/扩展画布文档。SDK 提供模块自有 InspectorAdapter 与 bindInspectorModel，不向核心解析器注入特殊语法。

自定义 Drawer 运行在原沙箱，返回受限控件树，交互通过事件 ID 回传；宿主校验树结构和值。异步取消、异常、无效树和超时均清理会话订阅。模块 settings 仅支持标准字段，不接受运行时 Drawer/命令按钮。

已移除图标按钮原生 title，只保留名称/描述浮层。新增 UI 验证上方常驻、上下复用 Drawer 的值互不干扰、按钮重置、异常隔离、无效树拒绝、取消清理和超时订阅清理。单元测试更新为 61 项。

## Inspector 与图片工具修正

格式转换和重命名迁至保存/导出图片窗口，左侧保留六类内容操作。Inspector 使用可拉伸的上下区，各自滚动，下方仅当前工具参数，不展示操作记录；所有应用/取消和尺寸控制移出画布。工具悬停改为实际 portal 提示框，显示名称和描述。

定位并修复 crop 输入依赖数组引用导致的反复载图/参数重置；裁剪输入以步骤内容为依赖。新增图片编辑 Electron 检查验证参数变化后请求数稳定、越界裁剪无法应用、参数只在 Inspector、分隔条可拖动、两区独立滚动及输出窗口含格式/命名设置。单元测试更新为 58 项，新增草稿应用/取消与输出参数不修改编辑流程的检查。调整尺寸仅暴露与可视手柄一致的精确宽高、比例锁和百分比预设。

## 面板独立设置与统一导航

修复同类型面板共用显示偏好的问题。面板菜单、左侧工具栏、快捷键和外部模块设置统一读取 windowId + type 独立配置；主菜单的类型偏好作为新面板默认。新增隔离测试验证修改第一个面板不会影响第二个。

移除专用 Type 按钮、portal 弹层及其样式。类型选择放在统一列表的“编辑 → 类型 → 具体类型”，通过同一个 MainMenu 控件渲染。选择状态使用 menuitemradio / aria-checked 表达，菜单定位在视口内。单元测试更新为 56 项，界面回归包含双面板显隐隔离和三级类型菜单。

## 导航与左侧工具栏修正

修复主菜单和画布导航的互斥行为，统一“类型 / 编辑”按钮高度与字号。快捷工具迁到画布左侧竖向图标栏，支持模块内 icon 相对路径、desc 悬停提示和文字回退；图片全部八类工具均保留入口。Inspector 已移除添加模块下拉框，输入源与预览目标改为标签和控件横向排列。配置说明见 [TOOLBAR_ICONS.md](./TOOLBAR_ICONS.md)。

单元测试更新为 55 项通过，新增图标快照、丢失图标重载保留旧版本、非法图标路径校验。Electron 工作区检查增加菜单互斥、导航尺寸一致、左栏宽度、图标提示、Inspector 移除旧入口和横向字段几何断言。打包 EXE 验收增加实际八个图标加载及左栏格式转换打开 Inspector 的检查。

## 资源接入与 Windows EXE 更新

本轮实现资源规则 resources、资源 handler 的 canAccept/open/dispose、会话授权读取、Blob URL 生命周期，以及无配置画布拒绝拖入。图片打开已接入同一协议，拖放、层级双击、文件打开和 Inspector 选择共用入口。规范见 [RESOURCE_INPUT.md](./RESOURCE_INPUT.md)。

当前单元测试为 54 项全部通过。三套 Electron 冒烟分别验证旧工作区、模块框架和资源接入；资源测试覆盖实际外部脚本二进制读取、拒绝后保留原内容、多资源批次不被单图片去重跳过、替换释放、连续打开串行授权、旧资源读取拒绝，以及音频示例实际 WAV 解码和波形生成。

独立代码审查发现多资源去重与并发授权两个问题，均先用真实 Electron 测试复现，再修复验证。

程序交付路径：`out/AssetFlow-win32-x64/AssetFlow.exe`。已新增真实打包程序检查脚本 `scripts/tests/packaged-smoke.ps1`：直接启动该 EXE，确认模块管理器、统一设置，并通过系统文件拖放协议导入 PNG，验证 Sharp Worker 处理后的图片预览。原先只运行源码 Electron 的验证不再作为 EXE 验收替代。

打包目录附带 `scripts/extensions/canvas_moudles/`（示例、SDK、文档）和 `BUILD_INFO.json`（构建时间）。请保留整个应用目录。音频示例包含播放器与实际波形，视频示例包含播放器及双轨预览布局，未实现音视频剪辑或容器音轨检测。以下为首次框架重构的历史记录，其“未打包”结论已被本轮交付取代。

## 已落地

- 主菜单模块管理器：关联 config.json、启用、停用、重新加载、移除关联；安装记录持久化、启动恢复。
- 类型注册数据为 id/name/desc，模块路径和生命周期记录独立维护。
- 系统固有模板不向扩展开放修改，菜单扩展只允许追加到公开位置。
- 配置驱动工具、菜单、默认快捷键、Inspector 字段、统一两栏设置；用户偏好独立保存。
- 外部脚本使用浏览器 ESM，每画布独立隔离 iframe；通过专用协议加载，不放宽宿主 script-src。
- 脚本命令注册、工具 preview/apply/cancel、输入输出、预览目标通知、文档状态保存。
- Ctrl+S 导出扩展画布文档，菜单打开文档，校验模块版本；未保存状态标记。
- 子能力 JSON 在模块内配置，随入口脚本保持校验后的快照，管理器重载后更新。
- 图片模块声明及 rembg 模型配置归属 scripts/extensions/canvas_moudles/image；已有图片后端保持复用。
- 提供地图示例、SDK 类型与可选基类、扩展规范及快速接入文档。

## 当前边界

- 新模块可即时加载；重载前需关闭该类型全部画布。不支持运行中代码无缝替换，不监视磁盘自动热更。
- 当前为目录关联，不提供 ZIP 解包、模块下载、签名仓库或自动更新。
- JSON 校验、路径读取和持久化失败保留旧快照；JS 激活错误显示在画布内，没有自动版本回滚。
- Inspector/设置当前提供 schema 字段，不支持外部 React 组件注入。画布可以绘制自己的 DOM/Canvas。
- 外部脚本没有任意磁盘、Node、Python 或本地模型执行权限。内置 rembg 仍通过原可信后端运行，本轮没有重新验收 AI 效果。
- 统一偏好目前按画布类型保存；不包含项目级、实例级设置覆盖。资源工作区文件仍主要保存资源层级，扩展画布文档需单独保存。
- 首次框架重构仅更新源码和 dist；本轮资源接口更新已重新生成 Windows 应用目录。Squirrel 安装包未生成。

后续便携版统一使用 `release/AssetFlow.exe`，执行 `npm run package` 或 `npm run package:local` 更新同一目录；中间文件仅在 `.cache` 内生成。应用运行中无法替换时构建会报出明确原因，不会生成新的发布目录。保留整个 release 目录一起分发。
