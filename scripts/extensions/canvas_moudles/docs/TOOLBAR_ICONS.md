# 工具栏、菜单与图标配置

画布顶部使用同一个 MainMenu 控件和菜单列表，固定入口为“编辑”，类型选择统一放在“编辑 → 类型 → 具体类型”，不再使用专门的 Type 按钮或弹窗。模块专属导航也使用相同控件。菜单互斥：打开另一个菜单会关闭先前菜单；打开子菜单保留祖先，并关闭同级分支。子菜单按视口定位，避免被窄画布裁切。

从面板打开的显示、快捷入口和工具设置按“面板 ID + 类型”独立保存。同类型两个面板不共享显隐、顺序、快捷键或参数。主菜单中的类型设置作为新面板默认值，已创建面板保持各自设置；设置面板标题会区分这两个范围。

工具快捷入口位于画布内容区域左侧，采用窄竖向图标栏。按钮的悬停提示显示工具名称、快捷键及描述；支持键盘聚焦和可访问名称。Inspector 不再提供“添加模块”下拉框，工具由左侧栏或“编辑 → 工具”选择，右侧继续展示处理步骤和所选工具参数。

在模块内存放图标，例如：

```text
scripts/extensions/canvas_moudles/my-tool/
  config.json
  index.js
  icons/
    brush.svg
```

```json
{
  "id": "my-tool.paint",
  "name": "绘制",
  "desc": "在画布上拖动绘制，右侧可调整画笔参数。",
  "icon": "./icons/brush.svg",
  "command": "my-tool.paint",
  "kind": "tool",
  "shortcut": "B"
}
```

上述对象放入 config.json 的 tools 数组。name 为名称，desc 为悬停描述，icon 为模块目录内相对路径。支持 SVG、PNG、WebP、JPEG，每张最多 128 KB；建议透明背景、24×24 视口，图标在界面显示为 20×20。

禁止绝对路径、远程 URL、父目录跳转及符号链接越界。管理器校验并读取图标快照，重载模块时一起更新；指定文件不存在或超限会报错并保留已加载旧模块。icon 可省略，此时显示名称首字；图片加载失败也使用文字回退。

图标配置只改变表现，不改变命令、快捷键和 Inspector 契约。“编辑 → 设置”中的显示开关、工具顺序和快捷键继续生效；隐藏单个工具或整个工具栏后，仍能通过编辑菜单调用。

内置图片模块的六类内容操作提供图标，位于 scripts/extensions/canvas_moudles/image/icons；格式和命名移到保存导出设置。地图示例通过自己的 icons/brush.svg 演示外部模块图标接入。SDK 的 CanvasTool 已公开可选 icon 和 desc 字段。
