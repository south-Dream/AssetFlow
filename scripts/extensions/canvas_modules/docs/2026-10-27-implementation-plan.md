# 画布模块框架实施计划

目标：主菜单模块管理器是外部模块进入系统注册表的唯一入口；系统模板不可覆盖，扩展通过 JSON 和 SDK 注册。

架构：主进程负责配置校验、持久化关联及读取脚本；渲染进程根据有效配置生成菜单、工具和设置。外部脚本在无同源权限的 iframe 中运行，通过版本化消息 SDK 通信，不获得 Node、Electron 或宿主 DOM。
