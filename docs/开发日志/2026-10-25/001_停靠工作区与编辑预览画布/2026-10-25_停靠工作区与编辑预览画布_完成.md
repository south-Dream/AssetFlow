# 开发完成

## 已完成

- 建立 Unity/Blender 风格的左侧 Hierarchy、中间画布、右侧 Inspector 容器。
- Hierarchy 和 Inspector 以单实例面板方式存在，随当前画布上下文工作。
- 中央画布默认两个，可在工作区设置中调整最大数量。
- 右键画布标签提供创建同类画布和移除画布。
- 画布标签可拖拽到中央区域进行标签/分屏布局。
- 编辑画布增加简洁类型标头和类型锁定提示。
- 增加只读结果预览区域，预留蓝图输出用途。
- 增加画布类型模型、资源类型校验模型和固定面板定义。
- 输出构建目录继续固定为 `out/AssetFlow-win32-x64`。

## 验证

- `npm run build` 通过。
- `npm test` 通过，22 项测试全部通过。
