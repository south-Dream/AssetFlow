# 第一版问题记录

## 用户反馈

1. 编辑画布仍显示“原始图片 / 处理结果”切换，保留了旧工作区交互。
2. 结果预览被做成独立的预览窗口，而不是当前画布下方的只读区域。
3. Hierarchy 和 Inspector 只能调整宽度，没有作为面板整体拖拽吸附。

## 核查结论

- `ImageWorkspace` 沿用旧 UI，并将两种图像状态做成页签。
- `PreviewCanvas`虽位于编辑组件中，但没有明确作为主编辑画布的底部区域呈现。
- 左右区域用固定网格实现，仅有 resize splitter，没有面板身份拖放。
- 原渲染器入口包含编码损坏与未闭合 JSX，阻碍可靠地继续局部修改。

## 处理

重建渲染器入口与图片工作区组件，保留现有图片处理 API 和 VisualEditor；中央画布只呈现处理结果，底部嵌入只读预览；Hierarchy/Inspector 标题与内容整体交换停靠，并使用共享 portal 槽位。
