# 多层级资源整理问题解决记录

- 停靠测试统一使用独立的 `hierarchy:<id>` 标识，并新增多个层级独立计数和移除测试。
- Hierarchy 标签右键增加移除当前层级操作；界面至少保留一个 Hierarchy，移除活动层级后切换到其他可用面板。
- 新层级名称通过检查已有标题分配，避免删除层级后重名。
- 系统文件导入完成后合并当前全局资产与本次导入结果，再使用大小写不敏感、统一分隔符的路径做精确或目录边界匹配。
- 层级成员使用 ID 去重；层级间拖动只添加引用，移除成员不删除共享资产。
- `npm run typecheck`、`npm test`（29 项）与 `npm run build` 均通过。
