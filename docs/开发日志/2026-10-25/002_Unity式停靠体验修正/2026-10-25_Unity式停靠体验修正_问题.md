# Unity 式停靠体验修正问题记录

## 已确认问题

- 面板拖出后若源标签组被折叠，目标组 ID 会失效，边缘/中心停靠可能无操作。
- 画布标签显示 UUID 后缀，不是用户可读的窗口名。
- 拖动面板后活动画布和 Inspector 上下文没有更新。
- 关闭当前画布后全局焦点与实际剩余布局可能不一致。
- 新版 CSS 仍混有旧固定列、浮动窗口和 portal 的废弃规则。
- Hierarchy 资源列表没有恢复移除资源入口。

## 预览区域辨析

当前 `ImageWorkspace` 中的 `.preview-area` 是编辑画布的图像视口，裁切/缩放编辑依赖它；它不是额外的底部预览面板。旧 `PreviewCanvas` 组件未被主界面引用，本次会删除孤立组件，不会删除编辑画布必需的视口。
