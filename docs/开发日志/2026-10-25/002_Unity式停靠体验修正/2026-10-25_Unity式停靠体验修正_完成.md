# Unity 式停靠体验修正完成

## 交付内容

- 用递归停靠树承载所有工作区面板，支持中心标签合并、四边分栏和分隔线调整。
- Hierarchy、Inspector 与编辑画布均可通过标题标签拖拽停靠；两个固定面板只有一个实例。
- 编辑画布可以新建、右键复制同类、移除；标签显示可读标题。
- 停靠或关闭画布时按画布 ID 保留编辑步骤、视口和导出设置，并更新 Inspector 绑定。
- 关闭画布后激活可见的替代画布；分栏比例保存在布局树中。
- 移除固定底部预览面板及过时浮动窗口样式；编辑画布保留其图像操作视口。
- Hierarchy 恢复资源移除操作。
