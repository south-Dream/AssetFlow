# Unity 式停靠体验修正问题解决记录

## 解决项

- 停靠移动改为从递归 dock tree 移除并插入同一面板实例；目标分组失效或唯一面板自拖时不破坏布局。
- 标签显示 Hierarchy、Inspector 和真实画布名称；拖动面板会更新活动画布及 Inspector 数据源。
- 关闭活动画布后选择仍开放的画布。
- 关闭画布后的备选画布会被显式激活；分栏比例存入停靠树，布局更新后不依赖临时组件状态。
- 画布步骤、裁切/缩放视口状态、导出目录和导出选项提升到按画布 ID 保存的工作区状态，面板重新挂载时保留。
- Hierarchy 资源项恢复移除按钮。
- 清理旧浮动窗口/portal CSS，并移除未使用的 PreviewCanvas 组件。

## 关于预览

移除的是独立固定的下方预览面板。图片画布内部保留一个编辑视口，供图片显示及裁切/缩放操作使用；它不会作为额外的预览窗口出现。

- `npm run typecheck` 通过。
