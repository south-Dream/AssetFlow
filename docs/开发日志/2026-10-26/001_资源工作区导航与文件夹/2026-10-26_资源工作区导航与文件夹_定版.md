# 资源工作区导航与文件夹定版

- 顶部从左至右为文件、编辑多级菜单；文件下收纳保存、导入、导出和设置，编辑下创建通用面板和只读结果预览面板。
- 移除内容区重复的面板标题、Crop/Resize 快捷按钮与画布导出栏。标签下保留紧凑窗口导航行，通用面板通过 Type 选择资源类型。
- 层级支持右键新建文件夹、嵌套组织、拖入多个系统文件/文件夹、层级内资源移动与跨层级引用。文件夹拖入保留目录结构。
- 文件菜单导出整个当前层级或选定资源/文件夹；默认导出名 asset，保留虚拟目录组织。结果预览应用当前编辑面板的处理步骤且不能编辑。
- 保存和加载工作区组织（JSON，引用源文件，不内嵌文件）；非图片资源可收纳与原样导出，图片处理沿用现有模块。
- Type 包含 img、audio、atlas、video、flow；尚未实现编辑器的类型显示明确空态，不伪装已支持编辑。
- 模块化实现菜单、层级数据、层级视图、只读预览和资源文件服务。完成后记录检查和打包结果。
