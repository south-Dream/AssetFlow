# 资源工作区导航与文件夹实现记录

## 已实现

- 左侧顶部多级菜单：文件 → 保存 / 导入 / 导出 / 设置；编辑 → 新面板窗口 / 应用后结果预览窗口。设置不再单独堆在顶栏右侧。
- 通用窗口名称为面板，标签下面保留紧凑导航行；Type 可选择 img、audio、atlas、video、flow。层级和 Inspector 不再重复输出窗口标题。
- 移除 img 内容区域内的标题、尺寸工具栏、Crop / Resize 快捷按钮与旧导出栏；图片参数操作仍通过 Inspector 进行。
- 层级右键新建文件夹，支持嵌套文件夹和折叠展开。支持多个系统文件、文件夹的导入与拖放，保留嵌套和空目录；普通音视频、数据文件等也可收纳。
- Ctrl 多选资源/文件夹，资源拖入文件夹即在本层级移动引用，跨层级建立引用；移除资源引用不删除磁盘文件。
- 文件菜单支持整个当前层级或选定资源/文件夹导出，默认名 asset。保留虚拟目录、空文件夹及原文件字节，同名资源添加序号，不覆盖已有导出目录。
- 保存/打开层级组织 JSON；重开时按源路径重新导入并映射资源 ID，校验资源引用与文件夹循环。
- 只读结果预览以普通停靠窗口创建，跟随当前编辑面板及选中图片应用处理步骤，不带编辑入口，不固定在底部，也不占编辑面板默认两个名额。

## 模块

- renderer/workspace/MainMenu.tsx：多级导航菜单。
- renderer/workspace/hierarchy.ts、HierarchyPanel.tsx：目录成员模型与树视图。
- renderer/workspace/ResultPanel.tsx：只读结果显示。
- main/resourceFiles.ts、resourceExport.ts、workspaceValidation.ts：文件对话框、层级导出与工作区校验。

## 验证与交付

- npm test：33 项通过，包含真实文件导出、同名资源、空目录、目录越界、选择子目录及无效工作区校验。
- npm run package:local：通过，包含 TypeScript 检查和生产构建。
- 输出：out/AssetFlow-win32-x64/AssetFlow.exe，覆盖更新现有唯一输出目录。
- Electron 隐藏窗口冒烟未通过，原因和后续讨论项见问题日志。不能将真实窗口交互标为已验收。

## 本版边界

- 非 img 编辑器尚未接入；对应 Type 显示待接入状态，但资源可组织及原样导出。
- 导出是层级源资源，不是蓝图执行结果；工作区 JSON 保存源文件引用和层级组织，不内嵌文件，也不保存停靠布局。
